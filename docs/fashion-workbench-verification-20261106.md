# 数字书桌第二轮验收 · 2026-11-06

当前本机网页版采用黑白排版、冷灰底色、亮柠檬色和书籍卡片。已有藏书时突出继续阅读与找书，空书库才展示添加引导；保留 React / TypeScript / Vite、Tailwind 和已有阅读引擎，没有增加运行时依赖。本轮不发布软件包，不构建 Tauri。

## 界面与交互

- 统一「添加书籍」入口：PDF 进入转换页，`.s2e` / 电子书 ZIP 导入书库。支持拖放。
- 书库提供书架／列表、标题／作者／文件夹搜索、最近阅读／添加／书名排序、在读／未开始筛选、继续阅读和明确的批量选择。
- 单击封面或书名阅读；详情、移动、移出书库放在独立菜单。移动位置采用下拉选择，按文件夹 ID 提交，可区分同名位置。
- 转换前显示实际 PDF 原页与真实页数；设置集中显示，模型参数可折叠，错误定位到相应输入框。
- 右上角任务中心持续显示后台进度，完成时提示结果；可阅读、下载、取消、重新转换、移除或批量清理。
- 非敏感任务记录保存在本机，服务重启后可找回结果。中断任务需重新输入 Key 重新转换，不提供断点续传。
- 任务清理仅处理上传副本、转换记录及产物；原始文件与书库独立。已选但尚未开始的上传副本也可以清理。
- 同一任务重复阅读复用书库记录；移出书库后仍可从保留的结果重新加入。

## ego-browser 验收

使用同一个 ego-browser 任务空间。桌面模拟视口为 1440 × 960 和 1440 × 1100，手机模拟视口为 390 × 844。页面操作、状态核对和截图均通过 ego-browser 完成。文件由自动化填入选择器；统一添加入口同时触发标准 `change` 事件。

| 场景 | 已验证结果 |
|---|---|
| 空书库／六本自制演示书 | 显示添加引导或书架，继续阅读显示真实保存的页码位置 |
| 搜索、无结果、清除筛选 | 作者检索只保留对应书籍，无结果可恢复全部书籍 |
| 书架／列表／文件夹 | 切换正常，文件夹筛选得到三本书；新建文件夹、勾选、取消与选择目标移动正常 |
| 更多菜单 | Escape 关闭并恢复到菜单按钮 |
| 真实 Python PDF inspect | 自制扫描 PDF 返回 3 页，原页预览正常；真实转换任务数为 0 |
| 校验 | 缺少 Key、页码超界均阻止提交并定位焦点；离开页面清空 Key |
| 模拟后台转换 | 离开转换页后任务继续，任务中心显示进度并通知完成 |
| 模拟取消、失败与重试 | 取消后可重试；失败显示错误，测试凭据被遮蔽；无真实 API 调用 |
| 结果阅读与重复打开 | 首次导入一本，刷新后再次从任务中心阅读，书库仍只有一本 |
| 实际下载 | ego-browser 接收 `.s2e` 下载并保存至临时目录 |
| 服务重启 | 已完成、失败、取消共三项历史恢复；已完成结果可重新打开 |
| 手机任务清理 | 清理后三项任务归零，书库仍保留一本；结果入口重置，焦点恢复任务按钮 |
| 未开始的上传副本 | 没有任务时也可经确认清理 |
| 深色／标准主题 | 等待实际背景与按钮颜色稳定后截图，再恢复标准外观 |
| 手机阅读 | 继续阅读可进入正文，阅读工具可打开并切换文字视图 |

任务中心有模态焦点限制、Escape 与关闭后的焦点恢复；手机侧栏在缩窄时自动收起。截图中的书与内容均为自制演示资料。

## 使用边界

全部验收使用 `/tmp` 独立数据目录，没有访问或更改原有阅读器书库。预览页展示六本自制演示书。真实模型可用性、OCR 准确率和长书质量未通过本轮端到端验证。手机为 Chromium 模拟视口，未验证真机 Safari。任务需要本地服务持续运行；关闭服务会停止转换。Tauri 仍仅有接入方案，没有桌面安装包。

视觉方向参考 [Rare UI](https://www.rareui.com/)；未复制其组件源码。ego lite 提示可更新，本轮沿用已安装版本，没有升级。
