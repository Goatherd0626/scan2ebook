## 使用边界

- 验收全部使用临时数据目录，没有修改或删除原有书库。
- 没有运行真实模型转换，因此不据此声称 DeepSeek 模型可用性、OCR 准确率或长书转换质量已通过端到端验证。
- 手机检查为 Chromium 模拟视口，未进行真机 Safari 或桌面 Safari 验证。
- 任务历史已持久化，服务重启后可以找回结果；任务中心提供转换副本与产物的清理入口。中断任务需要重新输入 Key 后重新转换，不提供断点续传。
- ego lite 当前版本提示可更新，本轮沿用已有版本完成验收，没有升级浏览器。
- Tauri 仅完成 [接入方案](tauri-desktop-plan.md)，未验证 Rust/sidecar 打包、签名、公证或桌面运行。
