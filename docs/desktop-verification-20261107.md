# macOS 桌面版验收记录 · 2026-11-07

环境：macOS 26.6.2、Apple Silicon。应用要求 macOS 14.4 起；其他系统版本及 Intel 未实机验收。

## 产物

- `dist/macos/Scan2Ebook.app`，设置页面更新后约 6.22 MiB。
- `dist/macos/Scan2Ebook_0.1.0_aarch64.dmg`，设置页面更新后约 2.39 MiB。
- DMG 可只读挂载，包含应用和指向「应用程序」的安装入口；复制后的应用通过本机签名校验。
- Rust 与 Swift 可执行文件只依赖系统库；包内不含 Python、Node、Chromium 或开发环境。
- 使用本机临时签名，未进行 Developer ID 签名和 Apple 公证，也未发布远端版本。

## Logo 更新

保留 `s2e.` 延续版字标，新增翻开的书与抬起书页组成的图形。网页侧栏使用图形与字标的组合，浏览器页签与 macOS 图标使用独立图形，见 [品牌资源](../design/brand/README.md)。字形和图形均为 SVG 路径，不增加运行时字体或依赖。

本次更新通过类型检查、图标与响应布局相关的 3 项现有测试及 npm 包内容检查。ego-browser 检查了深浅配色、Logo 返回书库、SVG 下载与 390px 模拟手机视口中的图形显示。应用与 DMG 已重新构建并通过本机签名校验，包内图标与本次源资源一致。上文的转换器、存储与付费接口验收边界继续适用。

## 设置页面更新

界面移除插件启停列表与顶栏 Aa 浮层。齿轮打开独立设置页，分为「外观」和「阅读排版」两个子页；修改即时预览、操作结束自动保存，各分类独立恢复默认。旧版关闭过的内置功能在启动时启用，已有字号与外观偏好继续保留。返回阅读时按原段落恢复相对视口的位置。

- TypeScript 检查、140 项前端测试与 npm 包内容检查通过。测试包含旧偏好迁移、分类切换、恢复默认、阅读返回，以及慢请求不能覆盖最新偏好的回归。正文草稿在设置往返中的暂存与焦点恢复、隐藏草稿的快捷键隔离、设置页面的浏览器查找快捷键通过 JSDOM 回归和独立代码复核。
- ego-browser 在隔离书库中实测浅色 / 护眼 / 深色、鼠标拖动字号及键盘调整行距 / 宽度、自动保存与刷新恢复、设置 URL 子页恢复、返回阅读段落。使用自制样书，未使用真实模型或用户书库。
- 390px 模拟手机视口中分类与滑条可用，无横向溢出；820×620 模拟小窗口中设置内容可纵向滚动、无横向溢出。这些不是原生窗口或真机操作证据。
- App 与 DMG 已重新构建，应用通过本机签名校验。包内 `frontend/` 与浏览器实测的 `reader/dist/` 共 7 个文件逐文件内容一致；本次没有通过原生窗口工具操作 WKWebView。
