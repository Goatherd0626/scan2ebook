# 书库精简与文件夹交互迭代

目标：按用户的奥卡姆剃刀要求删减文案与重复入口，以 Rare UI 文件夹形态和紧凑书籍改善首页。沿用现有 React/TypeScript 与本地 Python 转换，不增加框架依赖。

- [x] 保存此前实现为 Git 基线，建立 codex/compact-library 分支。
- [x] 第一轮：精简书库、导航和转换页文案；书籍缩小；实现可打开、可投放书籍、有层级导航的文件夹卡片。
- [x] 分别由新手、研究者、手机/键盘三个子 agent 使用独立样本书库实际操作，反馈具体问题。
- [x] 第二轮：落实有证据的反馈，保留必要错误、页码和密钥说明，不增加无关功能。
- [x] 清理已被 React 取代的旧首页与失效样式，让测试覆盖实际使用的界面。
- [x] ego-browser 复验桌面、窄屏、手机模拟视口以及添加、找书、文件夹、任务、阅读路径；检查截图。
- [x] 运行相应测试、类型检查、构建和包检查，保存精简验收记录并提交 Git。

参考：Rare UI 官方仓库的 Folder 组件。复制源码时保留其版权和实际许可证，并在 README 提供可见来源链接；不引入其动画依赖。

测试只用 /tmp 隔离数据和自制样书；转换仅使用假进程，不读取真实 Key，不调用付费模型，不改动原阅读器书库。Tauri 不在本轮实现范围。
