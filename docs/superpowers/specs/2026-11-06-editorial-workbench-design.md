# 数字书桌第二轮：视觉与使用路径

用户希望界面更 fashion，并授权主动完善交互。本轮继续在已确认的 React/TypeScript/Vite、Tailwind/shadcn 基础上实现本机网页版，不构建 Tauri，不发布远端，不运行真实付费转换。

视觉选择：高对比黑白、冷灰底色、一抹亮柠檬色、大字重与紧凑导航。书库使用有排版个性的书籍卡片，保留列表视图；已有书时取消宣传横幅，突出继续阅读和找书。阅读正文继续采用适合长文的衬线字体。动画只用于状态、悬停和面板展开，尊重降低动态效果设置。

使用路径：

1. 添加书籍统一接受 PDF/.s2e：PDF 进入转换设置，已有电子书直接导入；拖放与选择文件一致。
2. 书库提供继续阅读、即时搜索、排序、书架/列表切换、文件夹筛选和明确的批量选择；单击书卡阅读，查看详情作为独立操作。
3. 转换页以真实 PDF 预览与紧凑设置为主；Key 仅临时输入，提供整本/指定范围、折叠高级参数、明确错误、后台运行和完成后的阅读/下载入口。
4. 全局任务中心展示实际进度、完成/失败/中断状态，离开转换页仍能得知结果。非敏感任务元数据持久化，服务重启后可找回结果；中断任务需重新输入 Key 重新转换，不声称断点续传。
5. 清理仅覆盖转换副本与产物，须明确确认；已导入书库的书保持独立。重复点击同一转换结果的阅读入口应复用已有书籍，避免重复导入。

边界：保留原有书库格式、批注、书签、阅读进度与 DSH 兼容入口。测试只用独立临时数据目录、自制样书和假转换进程，不读取任何真实 Key，不访问用户原有书库。

验证：针对新增行为补测试；执行类型检查、相关测试、构建与打包；通过 ego-browser 操作空/有书书库、搜索/排序/筛选、智能添加、任务失败/取消/后台完成/重启恢复/清理、桌面/手机布局，并根据截图迭代。
