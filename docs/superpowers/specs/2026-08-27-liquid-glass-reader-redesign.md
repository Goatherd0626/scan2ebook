# 阅读器 Liquid Glass 视觉重构设计

## 目标与边界

在不改变阅读器现有功能、数据格式、插件接口和用户操作结果的前提下，重新设计首页、阅读区、左右侧栏、工具栏、弹窗与反馈状态。目标平台是桌面浏览器，视觉语言参考 macOS 最新 Liquid Glass，但不模拟原生窗口交通灯，也不为视觉效果引入新的前端依赖。

本次重构以 CSS、现有 DOM 结构的语义整理和图标替换为主。书库管理、PDF/文字渲染、同步滚动、书签、标注、高亮、搜索、阅读外观和正文编辑等业务逻辑保持不变。

## 设计原则

Liquid Glass 只用于顶层功能界面：工具栏、导航、侧边栏、Inspector、Popover、菜单和临时控制。正文、PDF、列表和表单属于内容层，使用稳定的实体或标准半透明材质，避免多层玻璃干扰阅读。

- 内容优先：书页和 PDF 始终拥有最高视觉权重。
- 克制用色：界面以系统中性色为主，Apple 蓝只表达选中和主要操作。
- 空间分层：通过材质、轻微高光和阴影表达层级，不使用粗边框和大面积实色按钮。
- 一致控件：同组操作共享玻璃胶囊；图标尺寸、命中区域、悬浮和按压反馈统一。
- 平台适配：保持可变窗口宽度、键盘焦点、降低透明度和减少动态效果支持。

## 视觉系统

### 色彩

浅色模式基础色：

- 系统背景 `#F5F5F7`
- 内容纸面 `#FFFFFF`
- 主文字 `#1D1D1F`
- 次级文字 `#6E6E73`
- 系统强调色 `#007AFF`
- 危险操作 `#FF3B30`

深色模式以 `#1C1C1E` 为背景、`#2C2C2E` 为内容层、`#F5F5F7` 为主文字。护眼模式只调整正文纸面与文字色，不改变应用导航层的系统层级。

玻璃材质使用半透明背景、`backdrop-filter`、一像素内外高光和低扩散阴影共同形成；不以单纯高斯模糊代替材质。浏览器不支持 `backdrop-filter` 或用户启用降低透明度时，回退到高不透明度实体表面。

### 字体与尺寸

- 工具栏、导航、按钮、表单：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", sans-serif`
- 书名与标题：系统 Display 字体，中文仍由苹方承接
- 正文：保留当前宋体族和用户可调字号、行距、正文宽度
- 界面字号采用 `12 / 13 / 15 / 17 / 22 / 28px` 层级
- 常用图标视觉尺寸为 `16–18px`，按钮命中区域不小于 `36px`，核心工具接近 `44px`

### 形状与动态

容器采用连续圆角：小控件 `9–11px`，胶囊组 `12–14px`，Popover `18px`，Modal `24px`。进入动效以轻微缩放和透明度为主，拖拽调整实时跟手；所有动画可中断并响应 `prefers-reduced-motion`。

## 页面结构

```text
┌────────────────── 悬浮玻璃工具栏 ──────────────────┐
├──────────────┬──────────────────────────┬───────────┤
│ 左侧玻璃导航 │  PDF / 文字实体内容层    │ 右 Inspector│
│ 书库·目录    │  中央玻璃分割控制岛      │ 注释·高亮  │
├──────────────┴──────────────────────────┴───────────┤
│                    edge-to-edge 背景                 │
└──────────────────────────────────────────────────────┘
```

### 顶部工具栏

工具栏从整条实色横栏改为悬浮功能层。左侧为侧栏开关与页面标签，中间保留文档上下文，右侧按“视图”“阅读工具”“文件”分组。组内统一使用图标控件，不混用字符符号和文字按钮；只有导入等低频且含义不明确的操作保留短文字。

标签改成轻量文档标签：当前标签用高亮玻璃表面，关闭按钮只在悬浮、聚焦或当前标签中出现。

### 首页书库

首页采用三栏桌面文稿管理器结构：左侧导航、中央书库内容、右侧常驻详情 Inspector。文件夹在中央区域原位展开，书籍和文件夹使用更大的行高、图标和留白。选择状态以蓝色半透明描边和柔和填充呈现，框选矩形使用系统蓝的低透明度区域。

首页顶部只保留新建文件夹、删除和导入三个动作，并分为普通组与主要动作。空状态移除 Emoji，使用现有或新增 SVG 图标。

### 阅读视图

PDF 区使用深色中性画布，页面阴影更轻；文字区使用完整纸面，不叠加玻璃卡片。左右面板可继续拖动。

双栏分割线改为细窄玻璃轨道。双向跳转按钮组成纵向控制岛并随分割线移动，悬浮时才增强材质与阴影，默认状态保持安静。

来源页框、item 框、书签、高亮和注释提示继续使用现有逻辑，只调整颜色、圆角和层级，使其与新系统一致。

### 左右侧栏

左侧书库/目录与右侧注释/高亮使用同一种 Inspector 结构：顶部标题与分段控件、可滚动内容、底部或上下文批量操作。导航层采用 regular glass；卡片和列表行属于内容层，使用低透明度标准表面。

目录/书签、注释/高亮的切换控件统一尺寸和状态。选中卡片的操作 Popover 锚定来源元素，点击空白、再次点击来源或按 Escape 均可关闭。

### Popover、Modal 与反馈

选区工具、搜索、阅读外观、注释卡片操作使用来源锚定的玻璃 Popover，操作按语义分组，危险操作单独分隔。正文页编辑器与设置使用居中的实体 Sheet，外围遮罩提供背景模糊；较大的正文编辑内容不使用透明玻璃，以保证长时间编辑可读性。

Toast 使用底部居中的紧凑玻璃胶囊，成功、警告和错误同时使用图标与文字，不只依赖颜色。

## 图标

继续使用用户导出的 SF Symbols SVG，并通过 CSS mask 继承状态颜色。新增资源优先采用：

- `magnifyingglass.svg`
- `plus.svg`
- `rectangle.split.2x1.svg`
- `sidebar.right.svg`
- `xmark.svg`

同步滚动暂时可复用上下箭头组合；若后续提供 `arrow.up.arrow.down.svg`，直接替换而不改变 DOM。所有图标按钮必须有 `aria-label` 和统一悬浮提示。

## 实现方式

新增一组语义化设计 token，逐步替换 `style.css` 中旧的暖色视觉变量，并保持旧 class 名供现有 JavaScript 和测试使用。只有当现有 DOM 无法表达工具组、标题层级或可访问状态时，才对 `index.html`、`core/app.js` 和插件生成模板做小范围结构调整。

重构顺序为：全局 token 与基础控件、应用框架、首页、阅读视图、侧栏、Popover/Modal、深色与护眼模式、响应式与无障碍状态。每一步都不改变事件绑定依赖的 ID、`data-*` 属性和插件扩展点。

## 验证

- 现有前端测试全集必须通过，确保所有功能事件和数据行为不变。
- Vite production build 必须成功。
- 视觉检查覆盖首页、PDF/文字/双栏、左右侧栏、搜索、阅读外观、标注操作和页编辑器。
- 检查浅色、深色、护眼、窄窗口、键盘焦点、降低透明度和减少动态效果。
- 不执行与本次视觉重构无关的后端改动。
