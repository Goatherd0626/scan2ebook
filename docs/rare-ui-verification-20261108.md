# Rare UI 交互验收 · 2026-11-08

本轮调整共享前端，不改变转换引擎或书库格式。参考 Rare UI 的 Toast、Bounce Sidebar、Gooey Nav、Delete Button 和 Notification Bell，并适配现有颜色、尺寸和键盘操作。不增加运行时依赖；来源和许可已加入第三方声明。

## 最终行为

- 操作反馈统一为 Toast，最多保留三条。支持状态、成功、失败、警告、持续等待和异步动作；悬停或聚焦时暂停消失，可单独关闭。删除、导入与任务管理沿用该入口，旧 Toast 实现和样式已清理。
- 设置分类和主要导航使用移动圆点，顶部标签使用液态连接。系统减少动态效果时静态显示，不改变路由、阅读段落或草稿。
- 删除在来源按钮旁展开确认，不遮挡整个页面。先取消聚焦，确认后才删除；Esc、点外部和导航均可取消。书籍删除只影响书库副本；转换清理明确说明上传副本与产物范围。
- 新的转换完成、失败和中断结果进入铃铛未读，历史任务不重复提醒。打开面板清空未读；提示中的查看结果会先关闭抽屉，再进入任务页。
- 后续前端反馈沿用 [前端交互约定](frontend-ui.md)。Web 与 macOS App 共用 `reader/src/`，桌面构建自动打包同一份前端。

浏览器使用隔离数据目录 `/tmp/scan2ebook-rare-ui-qa`、自制三页样书与本机模拟转换进程。测试输入仅为占位字符串，没有调用真实模型、付费接口或读取已有用户书库。通知验收证明前端反馈与任务状态交互，不代表真实模型识别质量或网络稳定性。

DMG 只读挂载至构建临时目录，复制并验证后卸载。未打开或自动操作原生窗口；手机与小窗口均为浏览器模拟视口，不能替代 WKWebView、原生对话框或真机验收。应用沿用本机临时签名，未做 Apple 公证。
