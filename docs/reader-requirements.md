# 阅读器功能需求（来自用户的原始描述，按提出时间整理）

> 状态标注：✅ 已实现 · ⏳ 二期待做 · ➖ 已讨论后放弃

## 一、整体形态（首版描述）

- [✅] 部署在本地，类似 Overleaf 的**双视图**：一边原 PDF、一边转换后的文字
- [✅] 两视图中间两个按钮：**文字→PDF**、**PDF→文字** 双向跳转
- [✅] **同步滚动**开关：滚轮滚动时同时滚动 PDF 和文字
- [✅] 独立网页阅读器，用文件选择（或拖拽）打开电子书
- [✅] PDF 与 JSON **打包成一个压缩文件**（.s2e：book.pdf + book.json）
- [✅] 打开后**加入阅读器列表**，自动识别书名/作者/ISBN 等必要信息
- [✅] 允许**双击手动编辑元数据**
- [✅] 可**创建文件夹**分类电子书
- [✅] 打开即存入**浏览器存储**（删原文件仍可阅读）
- [✅] 阅读器内删除会删存储副本；**批量删除、批量移动**到分类文件夹
- [✅] 左侧边栏上下两层：上层书库索引、下层当前书目录；**标签页**多本书切换
- [✅] **文字高亮（多色）/ 添加注释** + 右侧标注栏（可开关、拖拽宽度、双向跳转、搜索/筛选/多选），通过 `annotations.json` sidecar 随 `.s2e` 打包，不污染原始 JSON
- [✅] **页面编辑模式**（手动开启）：点击页来源框后按 `book.json` items 分块增删改；保存时原子写回本地电子书，受影响高亮移除、注释归档为历史注释
- [⏳] 二期：**复制引文**（可配 GB/T 7714 模板）、**标注导出**（Markdown/CSV）
- [✅] **脚注**：文字视图上标；**悬浮**出浮窗（移开消失）；**点击**在上标后插入浅灰小字括号脚注，再点收起
- [✅] **护眼**：护眼模式/深色模式/亮度/色温/字号/行距/阅读宽度（Apple 风格面板）
- [✅] 补充功能选定：**全文搜索、书签、进度记忆、PDF 双页摊开**

## 二、视图与导航细则（后续迭代）

- [✅] 视图可隐藏任一种：**双栏 / 仅 PDF / 仅文字**；仅 PDF 可**双页摊开**；仅文字单页流式
- [✅] **默认双视图**；**每本书保存自己的配置**（视图模式/摊开/同步，持久化）
- [✅] 视图切换按钮放在**顶栏搜索框右侧**（仅电子书视图显示，首页隐藏）
- [✅] PDF 摊开只在**仅 PDF 视图**生效；切双栏自动回退单页（配置仍记忆）
- [✅] 同步滚动按钮在双视图内（工具条，双栏时可见）
- [✅] PDF 双页摊开：**两列自动换行**（上下滚动，非单行横排）
- [✅] divider（交界）形态：零宽贴交界、白圆钮**骑线**、加粗 SF 箭头（→=跳对应文字段、←=跳对应 PDF 页）、1px 细线串珠
- [✅] 首页 URL/打开时恢复**阅读进度**（每本书记忆）

## 三、首页（Zotero 式，迭代定型）

- [✅] 首页标签页：书库信息、编辑、移动、导入区（不再有残留空状态框）
- [✅] **双击**进入电子书；**单击**选中（深色背景提示）→ 右侧信息面板
- [✅] 首页行内**不放**「打开/编辑/移动」按钮
- [✅] **右侧详情面板**（Zotero Info 风）：左标签右值；**悬停值框深色提示 → 单击直接修改 → 点别处自动保存**（无确认按钮）；书名亦可点改；文件夹下拉
- [✅] **移动**在侧边栏：新建文件夹后把书**拖进**文件夹（首页行/侧边栏行均可拖）
- [✅] 批量改名**多选**（SF Symbols：☰ list.bullet / 📁 folder.badge.plus / ⬆ square.and.arrow.up）
- [✅] 封面 logo **正方形**（详情 68×68 / 侧边栏 28×28，圆角保留）

## 四、搜索（VS Code 查找条风格，迭代定型）

- [✅] **顶栏搜索框保留**：可直接点击输入；**⌘F** 聚焦唤起
- [✅] **控件条浮于输入框正下方**（右上角阅读区）：计数「1 of N」、↑↓（SF 加粗箭头）、≡ 结果列表、× 清除关闭
- [✅] Enter/↑↓/Shift+F3 循环跳转；**无结果提示**
- [✅] 首页模式下搜索**书库元数据**（书名/作者/出版社/版次/ISBN/文件名/文件夹名）并过滤表格
- [✅] 开书搜索**正文**：高亮 + 当前项描边 + 平滑滚动
- [✅] 占位提示随场景切换（搜索书库… / 搜索正文…）
- [✅] 结果列表弹窗（≡ 展开）在控件条正下方
- [➖] 早期「Spotlight 式结果列表弹窗」方案已被 VS Code 查找条取代
